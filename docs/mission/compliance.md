## 검증 방법

1. `ffprobe`로 세로형 파일의 해상도, 길이, 비디오·오디오 스트림을 확인했다.
2. 실제 출력 프레임을 추출해 `assets/images/vertical-delivery-preview.png`에 보관했다.
3. `python -m c1_2_quality validate`와 단위 테스트로 매니페스트 경로를 확인했다.

가로형 원본은 제작 과정의 원본 증빙이며, 제출 기준 검증은 세로형 납품본을 대상으로 한다.
