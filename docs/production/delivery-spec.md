## 검수 순서

1. 모든 텍스트·로고·주요 인물이 세로형 안전 영역에 있는지 확인한다.
2. Scene 4의 브랜드명·슬로건·CTA가 마지막 2.5초에 보이는지 확인한다.
3. 내레이션과 BGM이 충돌하지 않는지, 오디오 피크가 과도하지 않은지 확인한다.
4. 최종 파일이 10.00초를 넘지 않는지 확인한다.
5. 파일을 `assets/video/`에 추가하고 매니페스트와 적합성 표를 갱신한다.
